## 🚀 Инструкция по запуску

### Вариант 1: Быстрый просмотр
Просто перейдите по ссылке на https://freeman90nya-cloud.github.io/emo-trainer/

### Вариант 2: Локальный запуск
Поскольку проект использует загрузку данных через `fetch`, для локального запуска рекомендуется использовать простой сервер (во избежание ограничений безопасности браузера CORS):

1. Откройте командную строку windows
2. Пропишите последовательно команды:
   c:
   cd C:\путь\к\папке\emo-trainer
   npx serve
3. Полученную ссылку http://localhost:3000 скопируйте в браузер
